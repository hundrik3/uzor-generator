# Генератор узоров

Небольшое веб-приложение для рисования симметричных узоров (в стиле калейдоскопа) на HTML5 canvas. Рисуешь мышкой или пальцем — штрихи автоматически отражаются по кругу и создают симметричный узор.

## Возможности

- Настройка степени симметрии (от 2 до 24 лучей)
- Регулировка толщины кисти
- Палитра готовых цветов + выбор произвольного цвета
- Режим «Радуга» — цвет штриха плавно меняется во время рисования
- Отмена последнего штриха (undo)
- Очистка холста
- Сохранение результата в PNG
- Работает как на десктопе (мышь), так и на мобильных устройствах (touch)

## Запуск

Проект не требует сборки и зависимостей — это чистые HTML/CSS/JS.

1. Склонируй репозиторий или скачай файлы.
2. Открой `index.html` в браузере.

Либо запусти локальный сервер, например:

```bash
npx serve .
```

## Структура проекта

- `index.html` — разметка страницы и панель управления
- `style.css` — стили интерфейса
- `script.js` — логика рисования и симметричного отражения на canvas
